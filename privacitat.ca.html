Informació de privacitat

Responsable i contacte

Alguer Balanyà és el responsable de les dades que facilita qui contacta amb Arenatec. Per a qualsevol consulta sobre privacitat o per exercir els teus drets, escriu a arenatec.info@gmail.com.

Consultes

Les dades que ens facilitis per correu o WhatsApp s'utilitzen per atendre i respondre la teva consulta. La base jurídica és l'interès legítim a gestionar les consultes que rebem. Les conservem durant un any des de l'última comunicació i després les eliminem.

El correu es gestiona amb Gmail. Si tries WhatsApp, la comunicació es fa a través d'aquest servei. Consulta la informació dels proveïdors sobre el seu tractament de dades i possibles transferències internacionals: Google i WhatsApp.

Visita al web

El web està allotjat a GitHub Pages. Segons GitHub, el servei registra l'adreça IP dels visitants per motius de seguretat. Pots consultar la informació de GitHub Pages i la seva declaració de privacitat. Els enllaços a Instagram i WhatsApp porten a serveis externs amb les seves pròpies polítiques.

Els teus drets

Pots sol·licitar l'accés, rectificació, supressió o limitació de les teves dades, oposar-te al tractament i sol·licitar la portabilitat quan sigui aplicable. Escriu al correu indicat. També pots presentar una reclamació a l'Agència Espanyola de Protecció de Dades.
